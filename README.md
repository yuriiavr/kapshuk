# Капшук

Сімейний бюджет за правилом 50/30/20 із Monobank, вбудований у Home Assistant.

- **Дохід місяця** ділиться на три кошики: базові потреби (50%), на себе (30%) і заощадження (20%). Відсотки й дохід
  можна змінити як типові, так і лише для одного місяця. Минулі місяці лишаються з тим планом, за яким жили.
- **Базові потреби.** Один список на всі місяці: оренда, комуналка, інтернет. Щомісяця на кожному пункті ставиться
  галочка «сплачено». Нова ціна діє з вибраного місяця й надалі або лише на один місяць. Якщо вказати слова з
  виписки («київстар»), галочка ставиться сама, щойно платіж з'являється в банку.
- **На себе.** Заплановані покупки для сім'ї на місяць і вішліст бажаного з ціною й посиланням. З вішліста покупка
  одним натиском переходить у план місяця.
- **Заощадження.** Тут видно банки Monobank і скільки відкладено за місяць.
- **Перерозподіл.** Суму можна перекинути між кошиками на один місяць, наприклад «12 500 із заощаджень на погашення
  кредиту в грудні». За бажання в потребах того місяця з'являється разовий платіж.
- **Monobank.** Кожен член сім'ї підключає свій особистий токен. Операції підтягуються кожні кілька хвилин, бо банк
  дає один запит на хвилину. Кошик операції визначається так:
  - перекази між своїми картками й людьми з сім'ї в бюджет не потрапляють;
  - поповнення банки йде в заощадження;
  - решта розкладається за типом магазину (MCC).
- **Виправлення.** Будь-яку операцію можна перенести в інший кошик. Тоді Капшук запам'ятовує магазин і наступні такі
  самі операції розкладає так само.
- **Адольф (голосовий помічник HA).** Через MCP він відповідає на «скільки лишилось», ставить «сплачено», записує
  готівку, планує покупки й робить перерозподіл.

## Як це влаштовано

| | |
|---|---|
| `server/` | Node 24, TypeScript без збірки, база `node:sqlite` |
| `web/` | React + Vite; `npm run build` збирає в `dist/web`, а віддає це сам сервер |
| `:8792`, у мережі | інтерфейс, вхід і `/api` |
| `127.0.0.1:8793` | `/mcp` для інтеграції Model Context Protocol у HA та `/sensors` для сенсорів |

**Вхід.** Окремих паролів немає: зайти може той, хто має доступ до Home Assistant.
- Картка на панелі HA показує свій токен HA і отримує одноразове посилання входу.
- Напряму в браузері вхід іде через сторінку входу HA (OAuth самого HA).

**Сесії.** Сесії Капшука тримаються 180 днів від останнього візиту. У базі зберігається лише їхній хеш.

**Токени Monobank.** Вони лежать тільки в базі на ноутбуці (`~/.local/share/kapshuk`, права 600) і назовні не
віддаються. Особистий токен Monobank дає лише перегляд балансу й виписки.

## Розробка

```bash
npm install
npm test           # бюджет на тимчасовій базі, без банку
npm run check      # типи
npm run dev        # інтерфейс з гарячим перезавантаженням, /api — на сервер на ноутбуці
KAPSHUK_NO_SYNC=1 DATA_DIR=./data npm start   # сервер локально без Monobank
```

## Розгортання на ноутбук із HA

```bash
npm run deploy     # збирає інтерфейс, везе server/ і dist/ на godos@192.168.31.94:~/kapshuk, перезапускає службу
```

Що налаштовано в Home Assistant:

- **MCP.** Інтеграція Model Context Protocol вказує на `http://127.0.0.1:8793/mcp`. Агент Gemini має її в
  `llm_hass_api`, а в промпті є рядок про «Капшук». Після додавання чи перейменування інструментів перезавантаж запис
  інтеграції, інакше HA лишить старий список.
- **Сенсори.** Файл `deploy/ha-rest.yaml` копіюється в `<config>/rest/kapshuk.yaml`, а застосовується службою
  `rest.reload`.
- **Панель.** У картці `home-dashboard` є плитка «Капшук» (адресу можна змінити параметром `kapshuk_url`).
