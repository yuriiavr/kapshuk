# Капшук

Витрати сім'ї з Monobank і чеків: що, де й за скільки купуємо. Вбудований у Home Assistant.

До 2026-11-23 Капшук ділив дохід на кошики 50/30/20. Тепер бюджет не ділимо: Капшук показує, куди пішли гроші, а в кінці
місяця — що саме купували й від чого можна відмовитись.

- **Витрати.** Операції з Monobank і вручну, по днях. Кожна витрата має категорію за типом магазину (MCC): продукти,
  кафе, таксі тощо. Є пошук за магазином чи товаром і фільтр за категорією.
- **Товари.** До будь-якої витрати можна дописати, що саме купили й за скільки.
- **Чеки.** Фото чека летить до ШІ (Gemini через проксі на ноутбуці, модель `gemini-3.1-flash-lite`). ШІ розпізнає
  товари, ціни, знижки, дату й магазин. Людина перевіряє, і чек записується:
  - до операції з банку з тією самою сумою (±3%, кілька днів довкола дати чека);
  - або окремим записом, якщо такої витрати в банку немає (готівка, інша картка).
  Фото зберігається на ноутбуці, його можна відкрити з операції.
- **Підсумок місяця.** Категорії з частками, де витрачали найбільше, групи товарів (молочне, солодощі, кава…) і що
  купували найчастіше. ШІ на запит дає пораду, від чого можна відмовитись.
- **Платежі.** Один список на всі місяці: оренда, комуналка, інтернет. Щомісяця на кожному пункті ставиться галочка
  «сплачено». Нова ціна діє з вибраного місяця й надалі або лише на один місяць. Якщо вказати слова з виписки
  («київстар»), галочка ставиться сама, щойно платіж з'являється в банку.
- **Хочу купити.** Заплановані покупки на місяць і вішліст бажаного з ціною й посиланням.
- **Monobank.** Кожен член сім'ї підключає свій особистий токен. Операції підтягуються кожні кілька хвилин, бо банк
  дає один запит на хвилину.
  - Перекази між своїми картками й людьми з сім'ї витратами не рахуються.
  - Поповнення банок іде окремо («у банку»).
  - Надходження від людей і фірм — дохід, повернення в магазин зменшують витрати.
- **Виправлення.** Категорію будь-якої операції можна змінити. Тоді Капшук запам'ятовує магазин і такі самі операції,
  минулі й нові, відносить туди ж.
- **Адольф (голосовий помічник HA).** Через MCP він відповідає, скільки й на що витратили, що купували, ставить
  «сплачено» й планує покупки. Витрат голосом не записує: усе приходить з банку й чеків.

## Як це влаштовано

| | |
|---|---|
| `server/` | Node 24, TypeScript без збірки, база `node:sqlite` |
| `web/` | React + Vite; `npm run build` збирає в `dist/web`, а віддає це сам сервер |
| `:8792`, у мережі | інтерфейс, вхід і `/api` |
| `127.0.0.1:8793` | `/mcp` для інтеграції Model Context Protocol у HA та `/sensors` для сенсорів |

**Вхід.** Окремих паролів немає: зайти може той, хто має доступ до Home Assistant.
- Картка на панелі HA показує свій токен HA і отримує одноразове посилання входу.
- Напряму в браузері вхід іде через сторінку входу HA (OAuth самого HA).

**Сесії.** Сесії Капшука тримаються 180 днів від останнього візиту. У базі зберігається лише їхній хеш.

**Токени Monobank.** Вони лежать тільки в базі на ноутбуці (`~/.local/share/kapshuk`, права 600) і назовні не
віддаються. Особистий токен Monobank дає лише перегляд балансу й виписки.

## Розробка

```bash
npm install
npm test           # на тимчасовій базі, без банку й без ШІ
npm run check      # типи
npm run dev        # інтерфейс з гарячим перезавантаженням, /api — на сервер на ноутбуці
KAPSHUK_NO_SYNC=1 DATA_DIR=./data npm start   # сервер локально без Monobank
```

## Розгортання на ноутбук із HA

```bash
npm run deploy     # збирає інтерфейс, везе server/ і dist/ на godos@192.168.31.94:~/kapshuk, перезапускає службу
```

Що налаштовано в Home Assistant:

- **MCP.** Інтеграція Model Context Protocol вказує на `http://127.0.0.1:8793/mcp`. Агент Gemini має її в
  `llm_hass_api`, а в промпті є рядок про «Капшук». Після додавання чи перейменування інструментів перезавантаж запис
  інтеграції, інакше HA лишить старий список.
- **Сенсори.** Файл `deploy/ha-rest.yaml` копіюється в `<config>/rest/kapshuk.yaml`, а застосовується службою
  `rest.reload`.
- **Панель.** У картці `home-dashboard` є плитка «Капшук» (адресу можна змінити параметром `kapshuk_url`).
